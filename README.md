# Session Switchboard

Session Switchboard contributes a right-hand split pane showing the selected Project's sessions, attention state, context use, branch, and name.

`send <number> <message>` writes and submits an explicit message to the selected terminal.
`stop <number> YES` deliberately requires confirmation before stopping a session.
The plugin never targets a session outside the selected Project's displayed list.

Run tests with `python -m unittest -v`.
